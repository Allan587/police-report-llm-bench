# Prompts de fases

Cada archivo es una instrucción concreta para Codex. **No** incluir todos en cada sesión: usar el de la fase activa indicado en `../advances.md`.

Inicio sugerido (desde la raíz del proyecto):

> Lee `AGENTS.md`, `context/goal.md`, `context/architecture.md`, `context/decisions.md` y `context/advances.md`. Audita el repositorio. Ejecuta exclusivamente `context/prompts/phase-01-browser-foundation.md`, implementa un incremento comprobable, ejecuta sus pruebas y actualiza `context/advances.md`. No presupongas funcionalidades existentes ni continúes a la siguiente fase sin evidencias.

Al cambiar de fase, sustituye el nombre del archivo. Divide fases amplias en entregables pequeños y verificables.
